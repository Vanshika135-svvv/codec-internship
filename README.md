# Artificial Intelligence Internship Projects - CODEC Technologies

**Author:** Vanshika Tiwari  
**Role:** AI Intern  

This repository contains the project submissions for the 1-Month Artificial Intelligence Internship at CODEC Technologies. It includes two foundational projects focusing on Machine Learning and Natural Language Processing (NLP), developed using Python and Jupyter Notebooks.

## 📁 Project 1: Stock Price Predictor
A machine learning model that predicts the next day's stock closing price based on historical market data. 

* **File:** `Stock_Price_Predictor.ipynb`
* **Objective:** Train a predictive model using historical stock data to forecast future closing prices.
* **Techniques Used:** Linear Regression, Time Series Train-Test Split, Model Evaluation (MSE, R2 Score).
* **Libraries:** `pandas`, `numpy`, `scikit-learn`, `yfinance`, `matplotlib`.
* **Data Source:** Real-time historical stock data fetched dynamically via the Yahoo Finance API.

## 📁 Project 2: Sentiment Analysis on Twitter Data
A Natural Language Processing (NLP) tool that analyzes a dataset of tweets and classifies the underlying sentiment as Positive, Negative, or Neutral.

* **File:** `Twitter_Sentiment_Analysis.ipynb`
* **Data File:** `tweets.json`
* **Objective:** Extract and categorize the emotional tone of social media text data.
* **Techniques Used:** Lexicon-based Sentiment Scoring, Data Wrangling, Distribution Visualization.
* **Libraries:** `pandas`, `nltk` (VADER SentimentIntensityAnalyzer), `matplotlib`, `seaborn`.
